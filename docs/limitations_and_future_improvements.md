# Limitations and Future Improvements

## Project Scope

This project uses a fictional fleet dataset created for learning and portfolio purposes.

The dataset was intentionally kept focused so that the analysis could concentrate on SQL practice, SLA monitoring, VOR downtime, garage performance, delay reasons, and operational interpretation.

It does not attempt to recreate every possible field or process used in a real fleet management environment.

## Why This Matters

Fleet operations can involve multiple stages before a vehicle returns to the road, including defect reporting, garage booking, recovery, garage arrival, diagnosis, repair authorisation, parts ordering, parts delivery, repair completion, driver updates, and follow-up chases.

The current dataset captures some of these stages, but not all of them. This means the analysis can identify patterns and investigation areas, but it should not be treated as a full root-cause attribution model.
